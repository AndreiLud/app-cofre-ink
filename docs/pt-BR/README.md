# Documentação

Os mesmos documentos existem em [inglês](../en/README.md). Os nomes de arquivo são os
mesmos nas duas pastas, então trocar `pt-BR` por `en` em qualquer endereço leva à mesma
página no outro idioma. O inglês é escrito primeiro e é de onde o outro sai.

| documento | o que ele responde |
| --- | --- |
| [Arquitetura](architecture.md) | como isto é montado, e a única ideia de que o resto decorre |
| [Modelo de dados](dataModel.md) | o que é guardado, em qual tabela, e as regras que valem em todas |
| [Fluxos](flows.md) | o que acontece, passo a passo, nos caminhos que importam |
| [API](api.md) | cada rota que o servidor responde, e o que ela espera |
| [Autenticação](authentication.md) | quem a pessoa é, como ela prova, e o que guarda a porta |
| [Configuração](configuration.md) | cada variável, o que ela faz, e o que quebra sem ela |
| [Publicação](deploy.md) | como publicar cada um dos três modos |
| [Problemas](troubleshooting.md) | as falhas que acontecem de verdade, e o que cada uma quer dizer |
| [Contribuir](contributing.md) | como trabalhar nisto sem brigar com as ferramentas |

As decisões por trás de tudo isso estão em [docs/adr](../adr), um registro por decisão
cara de desfazer, cada um com as alternativas recusadas e o motivo. Os documentos daqui
dizem como funciona. Aqueles dizem por que é assim.
